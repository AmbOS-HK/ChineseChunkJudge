## 2. 实现侧同步

- 新增 `impl/csharp/src/ChineseChunkJudge.Core/RuleEngine/ContractConsistencyRules.cs`：
  - `StrategyConsistencyRule`（CCJ-018，error）：`{type}` ≠ `options.strategyType`、`{targetSize}` ∉ 1..1500 或 ≠ `options.targetSize`；**前置**为 `strategy` 通过 CCJ-002 的正则（整体非法时只报 CCJ-002）。
  - `OversizedAgainstMaxRule`（CCJ-019，warning）：`maxChunkSize < 1500` 且 `charCount > maxChunkSize` 且 `charCount <= 1500`；`maxChunkSize = 1500` 时恒不触发。
  - `MetadataEqualityRule`（CCJ-020，error）：子块与父块五字段与 `document.metadata` 等值（`createTime` 按时刻比较）。
  - `ParentStructureRule`（CCJ-021，error）：父块 `index` 连续（含重复/缺号）、`charCount` 与码位数一致、偏移越界/长度非正。
- `ChunkRuleIds` 增 4 个常量；`DefaultBaseRuleIds` 与 `CreateDefaultRules()` 17 → 21；`ContractConstants.ContractVersion` → 0.10.0。
- `JudgeReport` 增可选 `EffectiveOptions`，`ChunkJudgeService` 在组装报告时原样回填。
- **CCJ-010 收编**：`ParentCoverageRule` 移除父块偏移越界/长度非正的报告（改为跳过，由 CCJ-021 报），保留「重叠 / 非精确子串 / 拼接不等价」三项，与 §8.4 新增说明一致。
