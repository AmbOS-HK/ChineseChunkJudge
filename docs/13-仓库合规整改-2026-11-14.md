## 3. 本次改动

- 新增 `CONTRIBUTING.md`：契约先行顺序、版本号三处同值、构建与测试命令、提交信息风格、PR 自查、术语红线（按 `docs/04` §3 执行）。
- 新增 `CODE_OF_CONDUCT.md`：改编自 Contributor Covenant 2.1，举报渠道 `support@ambos.cn`。
- 新增 `SECURITY.md`：受理范围限定为契约文本与 C# 参考实现；不承诺固定响应时限。
- 新增 `.github/workflows/ci.yml`：push / PR 到 `main` 时 restore + build + test，`dotnet-version: 10.0.x`。
- 新增 `.github/ISSUE_TEMPLATE/{bug_report,feature_request,config}.yml` 与 `.github/PULL_REQUEST_TEMPLATE.md`。
- 新增 `.gitattributes`（文本入库 LF，`.sln` 检出 CRLF）与 `.editorconfig`（UTF-8、缩进、末尾换行）。
- 修正 `README.md`：仓库结构树按磁盘实际补齐（`docs/00`–`12`、`templates/recommended/`、`HeadingPathTests.cs`）；快速开始的本机绝对路径改为 `<插件目录>` 占位；新增「版本与发布」「参与与自动化检查」两节。
