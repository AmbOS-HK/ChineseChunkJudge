## 3. 术语红线

对外文案、提交信息、代码注释中出现以下用法即判为口径错误：

- `判定单` → 应为「判定报告 / `JudgeReport`」。
- `双库`（单独使用，无「规划中」限定）→ 0.2.0 起已解禁，但必须指 Parent/Child 父子配对产物，不得指向两个独立向量库软件，也不得宣称阈值标准值。
- `五分流`（当作策略类型讲）→ 分流是路由维度，策略名须为 `{type}@{targetSize}`。
- `1500 例外`（未伴随契约变更）→ 现行是硬上限 + 告警，不是可豁免。

详见 `01-术语表.md` §C。

## 4. 文案解冻流程

1. 对应变更条目在 `02-契约演进.md` 中状态变为「已执行」。
2. 同步 `impl/` 与测试（rules.md §12 第 2 步）。
3. 回到本表，把该条判定改为「可发布」，并写明依据版本号。
4. 才允许改 README 或对外渠道文案。
